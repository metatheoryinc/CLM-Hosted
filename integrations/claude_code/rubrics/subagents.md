Choose the CHEAPEST tier that would do this subagent task well.

- haiku: look something up or report on it: find, read, list, count, check a fact, run a
  given command and report, or summarize existing material. The answer is found, not
  figured out.
- sonnet: a well-specified piece of work: implement a clearly described change, fix a
  described bug, write or update tests, or review a bounded diff or single task against a
  given spec or checklist. The what is decided; the subagent executes carefully.
- opus: open-ended or high-stakes judgment: design or plan, investigate an unknown root
  cause, review a whole branch or cross-cutting change for correctness and risk, weigh
  trade-offs, or large, ambiguous work across many files where mistakes are costly.

Judge by the work the task demands, not by how long it is or how it is worded. When between
two tiers, pick the cheaper one only if you are confident it would do the task well.
