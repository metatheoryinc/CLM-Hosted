Metatheory · CLM-Hosted

CLM for coding agents

A fast model that watches our Claude Code and Codex sessions and makes small decisions in about a fifth of a second: which model a subagent really needs, whether a turn claimed success it never checked, whether a command deserves a permission prompt.

CLM is a System One model: a frozen Qwen3-8B encoder plus small trained heads, hosted on our own RunPod and Cloudflare stack at clm.metatheory.dev. It answers when it is confident. When it isn't, it asks a second opinion.

A moment in a sessiona subagent is about to start, a turn ends, a tool is about to run
→
CLM answersprobabilities over the options, in ~0.2 s, from a head trained on our own sessions
→
Confident: CLM acts. It only ever makes things cheaper or stricter, never approves anything.
Unsure: a second opinion decides (Jev in ~0.2 s, or Opus in ~5–10 s). No answer means Claude Code or Codex carries on as usual.

Why it matters

What Metatheory gets out of it

Less spend on big models

Subagents default to the session's model, usually Opus. CLM moves the ones that don't need it, like lookups and single well-defined edits, to Sonnet or Haiku, automatically and only downward.

Fewer bad turns

"All tests pass" without running them, carrying on with a task the user already changed, trusting a truncated output. CLM catches these before the agent stops, in under a second, and the agent fixes them itself.

Our own data flywheel

Every decision is logged with its context. Fable, Jev and the judge label the hard cases, and the heads retrain on our real work. The more the team uses it, the better it fits how we work.

Ours, in both tools

The same hook runs in Claude Code and Codex, on a stack we host. Jev is an optional second opinion, not a dependency. On our own decisions CLM is already on par with Jev, and the two together beat either one.

Try it

Install it in two minutes

You need the CLM agent key; ask JT. A Jev key is optional and turns on CLM + Jev.

Claude Code

claude plugin marketplace add metatheoryinc/CLM-Hosted
claude plugin install clm@clm-hosted
  • Paste the key when asked, or under /plugin → clm → configure. It goes to your keychain.
  • /clm:status shows what CLM changed; /clm:off and /clm:on pause and resume it.
  • Whenever CLM acts you see a one-line CLM: … notice. Uninstall any time from /plugin.

Codex

git clone https://github.com/metatheoryinc/CLM-Hosted && cd CLM-Hosted
python3 integrations/codex/install.py
  • Codex asks you to review and trust the new hooks on its next start; they run once you do.
  • Behavior checks are active. Tool calls and subagents are logged only, because Codex encrypts a subagent's task.
  • install.py uninstall removes it.
Good to know

Limits today

  • The labelled sets are small (hundreds of decisions) and the labels come from models, not people. Human spot checks are the next step.
  • Turn traces, prompts and tool calls are sent to our CLM stack (and to Jev with a key), with secrets redacted on a best-effort basis. Everyone shares one key, so the team's records land in one pool.
  • CLM reads about 5,600 characters of a turn. Behaviors that depend on the middle of a long turn are its weakest spot.
  • If CLM or Jev errors or is slow, the hook does nothing and the session carries on as usual.
